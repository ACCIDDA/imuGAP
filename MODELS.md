# Stan Model Architectures in `imuGAP`

This document provides a comprehensive breakdown of the Stan model formulations implemented in `imuGAP`. It is divided into two parts:
1. **Theoretical Foundations**: Mathematical comparisons of unconstrained, constrained zero-sum, moving-offset, and direct-aggregation formulations.
2. **Practical & Algorithmic Implementation**: Engineering details on handling flexible multi-tier hierarchies, linear vector packing, parallel multi-threading (`map_rect`), weighted constraints, and mixed observation likelihoods.

---

## 1. Theoretical Foundations & Mathematical Formulations

`imuGAP` models time-varying, spatially hierarchical probabilities (e.g., State $\rightarrow$ County $\rightarrow$ School/Local Unit) across birth cohorts $c \in \{1, \dots, n_{\text{cohort}}\}$ and spatial locations $i \in \{1, \dots, n_{\text{locs}}\}$.

Let $\phi_{\text{state}, c} = \text{logit}^{-1}\left(B_c \beta_{\text{bs}}\right)$ represent the baseline state-level probability trajectory over cohorts $c$, generated by a B-spline basis $B$. Spatial variations at lower hierarchy tiers are introduced via layer offset parameters $\delta$.

The models in `imuGAP` implement three distinct mathematical approaches to spatial offsets and parent-child aggregation:

```
                       ┌─────────────────────────────────────────┐
                       │           Model Formulations            │
                       └────────────────────┬────────────────────┘
                                            │
        ┌───────────────────────────────────┼───────────────────────────────────┐
        ▼                                   ▼                                   ▼
┌───────────────┐                  ┌─────────────────┐                 ┌─────────────────┐
│ Unconstrained │                  │ Orthonormal     │                 │ Direct          │
│ Additive Logit│                  │ Zero-Sum Logit  │                 │ Aggregation     │
└───────┬───────┘                  └────────┬────────┘                 └────────┬────────┘
        │                                   │                                   │
        ▼                                   ▼                                   ▼
  Independent                        Zero-Sum Basis Q                       Bottom-Up
  Offset Draws                       + Moving Offset                        Odds Roll-Up
```

### Approach A: Unconstrained Additive Logit Model
*Files: `aggregate_logit.stan`, `direct_logit.stan`, `logit_unbalanced_shared.stan`*

#### Mathematical Formulation
Location probabilities at each tier $k$ are constructed additively in logit space:
$$\text{logit}(p_{\text{state}, c}) = \text{logit}(\phi_{\text{state}, c})$$
$$\text{logit}(p_{\text{county}, m, c}) = \text{logit}(\phi_{\text{state}, c}) + \delta_{\text{county}, m}$$
$$\text{logit}(p_{\text{school}, s, c}) = \text{logit}(\phi_{\text{state}, c}) + \delta_{\text{county}, m(s)} + \delta_{\text{school}, s}$$

Offset parameters $\delta$ are drawn independently across units:
$$\delta_i \sim \mathcal{N}\left(0, \sigma_{\text{layer}, k}^2\right)$$

#### Trade-offs & Theoretical Properties
- **Pros**: Computationally fast and simple; unconstrained parameter space allows unrolled vectorization.
- **Cons**: Sub-population probabilities $p_{school, s}$ do not mathematically aggregate to parent county probabilities $p_{county, m}$ under population weights ($w$), leading to structural incoherence across hierarchy tiers.

---

### Approach B: Orthonormal Zero-Sum Constrained Logit Model
*Files: `aggregate_logit_balanced_offset.stan`, `layer_offsets_constrained.stan`, `layer_constrained.stan`*

#### Mathematical Formulation
To eliminate non-identifiability and enforce local zero-mean balance, child offsets $\boldsymbol{\delta}_p$ for parent group $p$ with $K_p$ children are constrained to satisfy $\sum_{i \in \text{children}(p)} w_i \delta_i = 0$.

Rather than over-parameterizing with $K_p$ draws or using asymmetric negative-sum substitutions, $K_p - 1$ free unconstrained parameters $\mathbf{y}_p \sim \mathcal{N}(0, \sigma^2 I_{K_p-1})$ are transformed into $K_p$ constrained offsets using an **orthonormal basis matrix** $Q_p \in \mathbb{R}^{K_p \times (K_p - 1)}$:
$$\boldsymbol{\delta}_p = Q_p \cdot \mathbf{y}_p$$

Where $Q_p$ satisfies:
1. Orthonormality: $Q_p^\top Q_p = I_{K_p - 1}$
2. Zero-weighted sum: $w_p^\top Q_p = \mathbf{0}^\top$

To ensure exact population weighted aggregation in probability space, a cohort-specific **moving offset** $\theta_p(c)$ is calculated via 1D Newton-Raphson root finding:
$$\sum_{i \in \text{children}(p)} w_i \, \text{logit}^{-1}\left(\text{logit}(p_{\text{parent}, c}) + \theta_p(c) + \delta_i\right) = p_{\text{parent}, c}$$

#### Trade-offs & Theoretical Properties
- **Pros**: Strictly preserves isometry ($\det(Q_p^\top Q_p) = 1$, requiring zero log-Jacobian determinant correction); enforces exact weighted balance across sub-units.
- **Cons**: Requires Newton-Raphson root-finding loops per leapfrog step during MCMC sampling.

---

### Approach C: Direct Aggregation / Odds Roll-Up Model
*Files: `aggregate_odds.stan`, `aggregate_odds_balanced.stan`, `odds_shared.stan`*

#### Mathematical Formulation
Instead of enforcing top-down constraints, probabilities are evaluated at the lowest level (schools) and explicitly aggregated ("rolled up") to higher tiers using population weights $w$:

1. Compute lowest-tier probabilities:
   $$p_{\text{school}, s, c} = \text{logit}^{-1}\left(\text{logit}(\phi_{\text{state}, c}) + \delta_{\text{county}, m(s)} + \delta_{\text{school}, s}\right)$$

2. Roll up to county level:
   $$p_{\text{county}, m, c} = \sum_{s \in \text{children}(m)} w_s \, p_{\text{school}, s, c}$$

3. Roll up to state level:
   $$p_{\text{state}, c} = \sum_{m=1}^{n_{\text{county}}} w_m \, p_{\text{county}, m, c}$$

#### Trade-offs & Theoretical Properties
- **Pros**: Guarantees exact mathematical coherence of aggregated probabilities across all hierarchy levels by definition.
- **Cons**: Likelihood evaluations at upper levels induce complex non-linear coupling across all child parameters.

## 2. Practical & Algorithmic Implementation

### A. Flexible Multi-Tier Location Hierarchy Mapping

`imuGAP` supports arbitrary location hierarchies of varying depth and group sizes ($K_p$). The spatial structure is represented as 1D contiguous arrays using lookup maps computed in `transformed data`:

| Map Array | Dimension | Description |
| :--- | :--- | :--- |
| `layer_bounds` | $n_{\text{parent\_locs}}$ | Start indices for parent location groups in location space. |
| `parent_free_draw_map` | $2 \times n_{\text{parent\_locs}}$ | Start and end indices in the unconstrained draw vector $\mathbf{y}$. |
| `parent_full_loc_map` | $2 \times n_{\text{parent\_locs}}$ | Start and end indices in full non-root location space ($1 \dots n_{\text{locs}}-1$). |
| `layer_draw_map` | $2 \times (n_{\text{layers}}-1)$ | Start and end parameter indices per hierarchy layer $k$. |

```stan
// Convert layer_bounds to contiguous index ranges for parent groups
array[2, n_parent_locs] int parent_loc_ranges = bounds_to_range(layer_bounds, n_locs);
```

---

### B. Packed Linear Vector Storage for Orthonormal Projection Matrices

Stan requires all elements of an `array[] matrix` to share identical row and column dimensions. Because parent groups have varying numbers of children $K_p$, precomputed $Q_p$ matrices cannot be stored as a multi-dimensional matrix array.

Instead, `imuGAP` packs all $Q_p$ elements into a single contiguous 1D vector `Q_flat`:

$$\text{total\_Q\_elements} = \sum_{p=1}^{n_{\text{parent\_locs}}} K_p \cdot (K_p - 1)$$

```stan
// Precomputed packed linear vector in transformed data
vector[total_Q_elements] Q_flat;
array[n_parent_locs] int parent_Q_start;
array[n_parent_locs] int parent_Q_size;
```

#### Basis Matrix Construction Functions (`convenience.stan`)

1. **Unweighted Orthonormal Helmert Basis Matrix**:
   `build_zero_sum_matrix(int K)`
   $$Q_{i, k} = \frac{1}{\sqrt{k(k+1)}} \quad (i \le k), \quad Q_{k+1, k} = -\frac{k}{\sqrt{k(k+1)}}$$

2. **Weighted Orthonormal Basis Matrix**:
   `build_weighted_zero_sum_matrix(vector v)`
   Using cumulative squared weight prefix sums $S = \text{cumulative\_sum}(\text{square}(v))$:
   $$Q_{1:k, k} = \frac{v_{k+1} \cdot v_{1:k}}{\sqrt{S_k S_{k+1}}}, \quad Q_{k+1, k} = -\frac{S_k}{\sqrt{S_k S_{k+1}}}$$

### C. Multi-Threaded Parallel Execution via `map_rect`

To scale performance across multi-core systems (`STAN_NUM_THREADS` > 1), `imuGAP` parallelizes group offset transformations using Stan's `map_rect` interface.

```
                  ┌─────────────────────────────────────────┐
                  │    Unconstrained Draw Vector y_flat     │
                  └────────────────────┬────────────────────┘
                                       │
                ┌──────────────────────┼──────────────────────┐
                ▼                      ▼                      ▼
        ┌───────────────┐      ┌───────────────┐      ┌───────────────┐
        │ Thread 1      │      │ Thread 2      │      │ Thread T      │
        │ Group p=1     │      │ Group p=2     │      │ Group p=G     │
        │ Q_1 * theta_1 │      │ Q_2 * theta_2 │      │ Q_G * theta_G │
        └───────┬───────┘      └───────┬───────┘      └───────┬───────┘
                │                      │                      │
                └──────────────────────┼──────────────────────┘
                                       ▼
                  ┌─────────────────────────────────────────┐
                  │      Combined Mapped Offsets Vector     │
                  └─────────────────────────────────────────┘
```

#### Parallel Worker Function (`convenience.stan`)
```stan
vector apply_zero_sum_transform(
    vector phi,
    vector theta,
    array[] real real_data,
    array[] int int_data
) {
  int num_children = int_data[1];
  int num_free = num_children - 1;

  if (num_free == 0) {
    return rep_vector(0.0, 1);
  }

  matrix[num_children, num_free] Q_p = to_matrix(
    to_vector(real_data[1:(num_children * num_free)]),
    num_children,
    num_free
  );
  return Q_p * theta;
}
```

#### Multi-Threaded Model Call (`layer_constrained.stan`)
```stan
// Execute zero-sum transformations in parallel across CPU threads
vector[n_locs - 1] mapped_offsets = map_rect(
  apply_zero_sum_transform,
  phi_placeholder,
  theta_parent,
  real_data_parent,
  int_data_parent
);
off_layer = mapped_offsets';
```

### D. Mixed Observation Types & Likelihood Mapping

Observations can occur at any level of the spatial hierarchy (State, County, or School) and across multiple birth cohorts. `imuGAP` maps flexible observations to model probabilities using flattened index structures in `transformed_data/observation_map.stan`:

| Data Field | Description |
| :--- | :--- |
| `obs_loc_map` | Lookup index mapping observation $i$ to location $m \in \{1 \dots n_{\text{locs}}\}$. |
| `obs_cohort_map` | Lookup index mapping observation $i$ to cohort $c \in \{1 \dots n_{\text{cohort}}\}$. |
| `p_obs` | Model-predicted probability for observation $i$: `phi[(obs_loc_map[i]-1)*n_cohort + obs_cohort_map[i]]`. |

#### Censored Likelihoods (`model/censored.stan`)
Observations support exact counts ($Y_i$ successes out of $N_i$ trials) as well as interval-censored data ($Y_{\text{lower}, i} \le Y_i \le Y_{\text{upper}, i}$):

```stan
// Exact observations
y_obs ~ binomial(n_obs_cases, p_obs[obs_idx]);

// Censored observations
target += log_diff_exp(
  binomial_lcdf(y_upper | n_obs_cases, p_obs[cens_idx]),
  binomial_lcdf(y_lower - 1 | n_obs_cases, p_obs[cens_idx])
);
```

## Summary Model Selection Guide

| Model File | Spatial Offsets | Aggregation Guarantee | Parallelization | Best Used For |
| :--- | :--- | :--- | :--- | :--- |
| `aggregate_logit.stan` | Unconstrained additive logit | None (unbalanced) | Sequential | Baseline exploration, fast exploratory fitting |
| `aggregate_logit_balanced_offset.stan` | Orthonormal Zero-Sum + Moving Offset | Exact logit-space weighted balance | Multi-threaded (`map_rect`) | Hierarchical fitting with strict tier-to-tier population balance |
| `aggregate_odds_balanced.stan` | Orthonormal Zero-Sum + Bottom-Up Roll-Up | Exact odds roll-up aggregation | Multi-threaded (`map_rect`) | Direct probability aggregation models with balanced offsets |
| `direct_logit.stan` | Unconstrained additive logit | Bottom-up roll-up | Sequential | Vaccine dose dynamics with hazard functions |
